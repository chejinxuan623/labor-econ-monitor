# 关于本站

## 这是什么

一个劳动经济学文献监测站。每周从固定的期刊清单里抓取新发表的论文，做初步筛选后按主题归档，供人工判断这周读哪几篇。

它不试图覆盖全部文献。目标是把"这周有什么新东西"从几小时压缩到二十分钟。

## 数据来源

| 来源 | 用途 | 说明 |
| --- | --- | --- |
| Crossref | 期刊论文元数据 | 按 ISSN 逐刊抓取，无需 API key |
| NBER | 工作论文 | RSS 订阅，覆盖最新 WP |

期刊清单共 42 本，分两档：

- **T1 综合顶刊**（12 本）：AER、QJE、JPE、REStud、Econometrica、REStat、AEJ 系列、JEEA、Economic Journal
- **T2 领域刊**（30 本）：JOLE、JHR、Labour Economics、ILR Review、Journal of Public Economics 等

## 筛选规则

抓取后经过三道处理：

**1. 去重**

按 DOI 精确匹配 → 标题标准化后匹配 → 相似度 ≥ 0.90 且作者重合 ≥ 1 人。前两级自动判定，第三级标为"待确认"进入人工复核。

**2. 相关性初筛**

- 劳动、人口、教育类专刊：全部保留
- 综合刊：标题需命中劳动经济学词表（中英文各约 40 个词）

综合刊不按标题全过滤的原因很直接：QJE 一期里可能只有一篇讲劳动市场，但 JOLE 里每篇都是。

**3. 期刊分级**

按刊物层级排序，顶刊在前。这不是质量评分，只表示"优先看"。

## 人工分档

自动筛选只能决定"值不值得看"，决定"要不要精读"的是人。三档：

- **A 必读**：与研究直接相关，需填完整五问（问题、识别策略、数据、结果、与我们的关系）
- **B 可读**：方法或结论有参考价值，填三问
- **C 略过**：只留元数据

## 已知局限

**收录有滞后。** 抓取按出版日期过滤，在线优先（online first）的论文可能先出现在期刊网站、后进入元数据。

**只看标题。** 相关性初筛基于标题词表，标题不含关键词但内容相关的论文会漏掉。这也是为什么要保留 T1/T2 分级——至少不会错过顶刊上的。

**没有全文。** 本站只做索引，不存储论文全文。点击标题会跳到 DOI 原始页面。

**人工分档尚未开始。** 当前待审论文的档位都是空的，等第一轮人工过完才会有内容。
